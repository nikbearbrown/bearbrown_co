# Brand guidebook for bearbrown.co

## Executive summary

**What this is.** The InDesign brand guidebook for bearbrown.co: 32 pages covering the Bear Brown signature and BB monogram, the color palette (light and dark), typography, online and stationery specs, imagery rules and contact. It is the site's neutral, colors-logos-typography-only identity.

**Why it is here.** This folder is a working resource for editing the guidebook in InDesign. It is **not public**: Next.js serves only `public/`, so nothing in `resources/` is on the web. It is committed to GitHub so the source files live with the site.

**What it found.** The template's page designs were kept; the text was written from the site's real tokens (`app/globals.css`) and the brand files. Contrast ratios on the color pages are computed, not quoted from the site's CSS comments, which overstate them (ink on cream is 10.98:1, not 12.8:1).

## Files

## Opening it

- **Fonts.** Headings are EB Garamond (OTF) and body text is Inter, the same two fonts the site uses. Both are free on Google Fonts. The original template used Minion Pro, Open Sans and Philosopher; they were replaced so the guidebook matches the site.
- **Image frames.** The tinted blocks where the template had gray image placeholders are flat sand-colored fields on purpose: this site uses no photography.
- **Portraits of Bear** belong to nikbearbrown.com, not here.
